Speech demo

This page loads @degreesign/voice from jsDelivr, so you can try speech to text, text to speech and voice cloning before installing the package.

Speech to text

Whisper base runs locally. The demo uses Quality.Low, a 59 MB download on first use. Record from the microphone or pick an audio file.

Ready.

Text to speech

Pick a voice, tune the sliders and press Speak. The first run downloads the voice and keeps it cached. Pitch and rate apply after synthesis. Temperature and seed only affect the MOSS voices (Female and Male). Record a reference below, then tick it to speak with your clone.

Ready.

Voice cloning

Record a short reference from the microphone. The first run downloads the 45 MB MOSS encoder. Tick the reference and press Speak to render the selected voice as the recording.
