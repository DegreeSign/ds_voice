Capabilities

Two directions. One small package.

The same entry handles recognition and synthesis. Models download once, then every decode runs on the machine in front of you.

Speech to text

Stream a live transcript from the microphone, a file, a URL or raw PCM. Whisper base runs locally with automatic language detection.

streaming word timing

Text to speech

Render two 48 kHz MOSS voices with pitch, rate, gain, temperature and seed controls. The text selects one of 20 languages.

48 kHz 20 languages

Voice cloning

Record three seconds, encode it with the MOSS tokenizer and reuse the codes as a speaking reference. No second recording needed.

3 s reference 45 MB encoder

Dictation

A headless controller owns the worker, microphone capture, pause state and partial text. Bring your own markup and copy.

worker partials

How it works

From air to text, from text to air.

One entry point chooses the right model, source and platform. The heavy work stays in WebAssembly on the CPU.

01

Capture

Microphone, PCM, Blob, URL or path. The first source present wins, so the same API fits a page, a worker or a Node script.

02

Decode

Whisper base streams through SIMD kernels with bounded memory, live partial text and decode timing measured over the model alone.

03

Speak

MOSS renders 48 kHz audio, optionally with a recorded reference and pitch, rate or gain changes applied after synthesis.

Install

Add it to your project.

One package for both directions. Node 24 or newer, or load the browser bundle straight from a CDN.

npm install @degreesign/voice

The dictation controller lives at @degreesign/voice/dictation. 

import {
    Language,
    transcribe,
} from "@degreesign/voice";

const session = transcribe({
    language: Language.auto,
});
const result = await session.done;

console.log(result.text, result.meta.rtf);
